## SpeedFast — Sistema de Gestión de Entregas

Proyecto académico en Java para la asignatura Desarrollo Orientado a Objetos II (Duoc UC). Modela el sistema de pedidos y entregas de la empresa ficticia SpeedFast.



## 🧱 Estructura general del proyecto
```Organización de Packages
📁 src/
├── model/       # Lógica del dominio: pedidos, estados, repartidores y gestión de datos.
├── vista        # Ventanas Swing. Muestran y capturan datos usando las clases del modelo.
├── utils/       # Clases Utilitarias. Datos de ejemplo para pruebas. No forma parte del modelo.

````
